## Python Banking Program

A simple Python banking program for practicing core programming concepts through common banking operations. Users can manage an account, check its balance, deposit money, and withdraw funds.

## Features

- Check an account balance
- Deposit money
- Withdraw money, with checks to prevent invalid withdrawals
- Clear prompts and feedback for each operation

## Requirements

- Python 3.8 or later

No third-party packages are required for the basic version.
